**조사일:** 2026-06-06  
**대상 앱:** 토스 미니앱 `오늘 뭐 챙기지?` / appName `today-what-to-bring`  
**조사 목적:** 현재 PRD의 상황 카드가 실제 사람들이 겪는 준비물 누락·깜빡함·정보 분산 문제와 맞는지 확인하고, MVP 템플릿/카피/우선순위에 반영한다.

## 1. 조사 범위와 신뢰도

### 조사 대상 상황
현재 앱의 MVP 카드와 직접 관련된 상황만 조사했다.

- 출근/첫 출근
- 외출/아기 외출
- 비 오는 날/우산
- 운동/헬스장
- 병원 방문
- 퇴근길 장보기
- 아이 등원/등교
- 출장/외근
- 골프
- 캠핑
- 국내여행
- 해외여행
- 등산

### 출처 기준
- 공개 블로그, 커뮤니티, 게시판, Q&A, 기사성 글을 우선 확인했다.
- 직접 접근 가능한 본문을 우선 근거로 삼았다.
- 일부 커뮤니티/검색결과는 접근/파싱 제한 때문에 스니펫 중심으로만 확인했다. 이 경우 아래 표에서 보수적으로 해석했다.
- 실제 사용자 원문 20개 이상을 완전히 수집·코딩하는 작업은 별도 심화 조사로 남길 수 있다.

## 2. 핵심 결론

1. **앱 방향은 실제 불편과 잘 맞는다.**  
   사람들이 반복적으로 겪는 문제는 “무엇을 챙겨야 하는지 몰라서”보다 **상황별로 챙길 게 흩어져 있고, 작은 필수품을 마지막 순간에 빼먹는 것**이다.

2. **현재 PRD의 상황 카드 구성은 대체로 타당하다.**  
   병원, 등원/등교, 출장/외근, 캠핑, 골프, 여행, 등산은 준비물 누락 불편이 뚜렷하다. 출근/외출/운동/비 오는 날도 일상성은 높지만, 증거 강도는 블로그/체크리스트 중심이라 카피에서 “가벼운 마지막 확인”으로 포지셔닝하는 게 좋다.

3. **MVP 템플릿은 ‘마지막 순간 체크’와 ‘고위험 누락 항목’이 중요하다.**  
   여권, 신분증, 법인카드, 아이 물병/수저통, 충전기, 보조배터리, 골프공/장갑, 캠핑 연료/랜턴 배터리 등은 빠뜨렸을 때 피해가 크다.

4. **복잡한 알림/AI보다 상황별 프리셋 + 커스텀 항목 + 최근 루틴이 MVP에 적합하다.**  
   많은 사례가 “체크리스트가 필요하다”, “한둘 빼먹는다”, “매번 확인해야 한다”에 가깝다. 현재 MVP 범위와 잘 맞는다.

## 4. MVP 템플릿 변경 제안

### 4.1 바로 반영 추천
현재 PRD의 기본 카드 13종은 유지하되, 아래 항목을 강조한다.

#### 병원
- 신분증을 1번 항목으로 유지한다.
- `모바일 건강보험증 확인`은 직접 설치 유도나 외부 링크 없이 보조 문구로만 검토한다.
- 의료 조언/예약/추천 금지 고지는 유지한다.

#### 아이 등원/등교
- `물병`, `수저통/식기`, `알림장/앱 공지 확인`, `여벌옷`, `우산/외투`를 기본 항목으로 강화한다.
- 카피: `알림장부터 물병까지, 아침에 한 번 더 확인해요.`

#### 출장/외근
- `노트북`, `충전기`, `신분증`, `교통 티켓/예약`, `발표자료/문서`, `명함`, `결제 수단`을 우선 항목으로 둔다.
- 해외출장은 MVP 기본 카드에서는 태그로만 연결하고, 해외여행 카드와 중복되지 않게 한다.

#### 캠핑
- `랜턴/배터리`, `버너/연료`, `쓰레기봉투`, `예약/입실 시간`은 누락 체감이 커서 유지한다.
- `세제/수세미/키친타월`은 MVP 항목에 추가 검토 가치가 있다.

#### 골프
- `골프공/티`, `장갑`, `골프화`, `거리측정기`, `티오프 시간`은 유지한다.
- `볼마커`, `차키/현금`, `간식`은 초보 라운딩에서 유의미하므로 추가 후보.

#### 국내/해외여행
- 국내여행: `신분증`, `충전기`, `세면도구`, `상비약`, `숙소/교통 예약 확인` 유지.
- 해외여행: `여권`, `항공권`, `현지 결제수단/환전`, `eSIM/로밍`, `상비약` 유지.
- `멀티어댑터`는 해외여행 기본 항목에 추가 추천.

#### 등산
- `물`, `간식`, `모자/선크림`, `바람막이`, `보조배터리` 유지.
- `헤드랜턴/손전등`은 장거리/오후 산행 선택 항목으로 추가 후보.

### 4.2 MVP에서 하지 않는 게 좋은 것
- 커뮤니티에서 보이는 모든 세부 상황을 카드로 늘리지 않는다.
- `아기 외출`, `첫 출근`, `해외출장`, `차박`, `첫 라운딩`, `장거리 등산`은 별도 카드가 아니라 검색 태그/추가 항목/프로덕션 후보로 둔다.
- 위치/날씨/가족 공유/AI 붙여넣기 변환은 프로덕션 후보로 둔다.

## 5. PRD 반영 판단

### 형의 범위 결정
- 이번 조사에서 도출된 `오늘만 항목`, `고위험 항목 표시`, `출발 전 30초 체크`, `상황별 질문`, `정보 붙여넣기/수집` 방향은 서비스 확장 아이디어로는 유효하지만 **MVP에는 반영하지 않는다**.
- 이유: 현재 MVP가 이미 홈 검색, 커스텀 항목, 홈 보기 모드, 카드/항목 순서 변경, 최근 루틴, Analytics까지 포함하므로 추가 UX 개념을 넣으면 구현·QA·검수 복잡도가 커진다.
- 처리: 아래 항목들은 **추후 업데이트 후보**로만 보관하고, 현재 MVP는 기존 PRD의 단순한 상황별 프리셋 체크리스트 구조를 유지한다.

### 유지할 결정
- MVP 카드 13종 유지.
- 커스텀 항목 추가/삭제/순서 변경 MVP 포함.
- 카드 순서 변경은 단순 버튼/편집 모드로 제한.
- 외부 서버/로그인/알림/날씨/AI 제외.

### 추후 업데이트 후보로 보관
- 오늘만 항목: 이번 체크에만 필요한 임시 준비물.
- 고위험 항목 표시: 여권, 신분증, 법인카드, 아이 물병/수저통처럼 빠뜨리면 피해가 큰 항목 강조.
- 출발 전 30초 체크: 체크리스트 상단에 핵심 항목 3~5개만 먼저 보여주는 빠른 확인 모드.
- 상황별 질문: 캠핑/등산/골프/해외여행 등에서 1개 질문으로 항목을 살짝 보정하는 방식.
- 정보 수집 UX: 알림장/카톡/메모/회사 공지에서 본 항목을 붙여넣거나 오늘만 추가하는 흐름.

### 추가 변경 결정 필요
1. **해외여행 기본 항목에 `멀티어댑터`를 추가할지 결정.**  
   근거 강도 높음. 해외여행 누락 항목으로 자주 등장한다.

2. **캠핑 기본 항목에 `세제/수세미/키친타월`을 추가할지 결정.**  
   근거 강도 중간~높음. 캠핑 소모품 누락 불편과 잘 맞는다.

3. **골프 기본 항목에 `볼마커`, `차키/현금`, `간식` 중 어디까지 넣을지 결정.**  
   너무 많아지면 초경량성이 떨어진다. 추천은 `볼마커`만 기본 추가, 나머지는 커스텀/초보 태그.

4. **등산 기본 항목에 `손전등/헤드랜턴`을 넣을지 결정.**  
   안전 항목이지만 짧은 산행에는 과할 수 있다. 추천은 `선택` 표기.

5. **아이 등원/등교 항목을 ‘매일’ 중심으로 정리할지 결정.**  
   추천은 MVP에서 섹션을 나누지 않고 항목명에 `물병`, `알림장/앱 공지`, `여벌옷`, `우산/외투`만 명확히 둔다.

- 해외여행: `여권, eSIM, 멀티어댑터까지 공항 가기 전 확인.`
